## 1. UNK-05：文字渲染、字体度量、控制符排版与禁则处理

### 1.1 字体选择、字符集与字号缩放（`0x441b00`, `0x440cf0`）

1. **字体名表**：
   - `font_family == 0`（默认，`0x440cf0`）：`0x46d110` → `"ＭＳ ゴシック"`（CP932；`KhimeDL_CHS.exe` 改写为 `"黑体"`）。
   - `font_family == 1`（`^fm` 触发）：`0x46e194` → `"ＭＳ 明朝"`（CP932；`KhimeDL_CHS.exe` 改写为 `"黑体"`）。
   - 字符集 `lfCharSet`：原版在全部 **11 处** `CreateFontA` / `LOGFONT` 构造点均使用 `0x80`（`SHIFTJIS_CHARSET`）；`KhimeDL_CHS.exe` 将这 11 处全部改为 `0x86`（`GB2312_CHARSET`）：`0x40365a`, `0x44c733`, `0x44f20e`, `0x44f24f`, `0x44f58b`, `0x44f5c9`, `0x44f8de`, `0x44f913`, `0x44fcd3`, `0x44fff0`, `0x450256`。
2. **字号档位换算函数 `0x441b00(scale: u16)`**（设基准像素高度 `base = *(i16*)(this + 0x18e)`）：
   - `scale == 0` → `base / 2`
   - `scale == 1` → `base`（默认档位）
   - `scale == 2` → `(base * 3) / 2`
   - `scale == 3` → `base * 2`
   - `scale >= 4` → `base * (scale - 1)`
3. **默认文字对象初始化（`0x440cf0` / `0x416000` / `0x40fbf0`）**：
   - **主文本框 `tbox+0x6c`**：字号在 `tbox` 布局/初始化时设定，渲染模式在 `0x440d52` 固定置为 **`mode = 3`**（`WORD [ecx - 0x34] = 3`），默认前景色 `0x00FFFFFF`（白，未置 `0xFF000000` 高字节），默认字重 `bold = 0`, `italic = 0`, `font = 0`（ゴシック），对齐 `align = 0`，速度取全局 `text_speed`（`0x47137a`）。
   - **说话人/状态栏 `tbox+0x70`**：`0x416000` 建 10 字槽，基准字号 `base = 15`，渲染模式 **`mode = 0`**，位置 `(44, 0)`。
   - **存档槽摘要文字 `savescrn`**：`0x40fbf0` 创建 `base = 19`（`0x13`）字号预览文本，写于槽位预览层（对应 `saveconf.lwg` 的 `321×78` 卡片）。
   - **选项文本 `select0..5` (`sel_a01.lwg` / `sel_q01.lwg`)**：文本框在 `(55, 17)`，宽 `540×36`。

### 1.2 6 种字形光栅化模式与旋转度量（`0x44f080` 分派器）

文本字符表面由 `0x44f080` 按 `*(u16*)(glyph + 0x1ac)`（`mode 0..=5`）分派生成 32-bit BGRA 位图（内部使用**倒置 Alpha：`0x00` = 完全不透明，`0xFF` = 完全透明**）：

| Mode | 函数 VA | GDI API / 格式 | 字重 (`lfWeight`) | 旋转 / 竖排支持 | 阴影与像素合成公式 | 等宽与度量覆写 |
|---|---|---|---|---|---|---|
| `0` | `0x44f1b0` | `GetGlyphOutlineA` (`GGO_BITMAP = 1`) | `bold ? 700 : 0` | 创建水平字体 + `"@"` 竖排字体；`vert != 0` 时 `MAT2 = {0,-1, 1,0}`（顺时针 90°） | 仅写入 foreground BGR (`0xFFFFFF` 或指定色)，无阴影 | 遵循 GDI `GLYPHMETRICS` (`gmCellIncX/Y`, `gmptGlyphOrigin`) |
| `1` | `0x44f530` | `GetGlyphOutlineA` (`GGO_GRAY8_BITMAP = 6`) | `bold ? 700 : 0` | 支持 `"@"` 竖排与 `MAT2` 90° | 灰度 `g ∈ 0..=64` 映射 `val = ((g * 255) >> 6) >> 3` (`0..=31`) 写 `B=G=R=val`，调 `0x435ab0(color)` + `0x435770(0x16)`（`mode 0x16` 着色淡入，读 `src_A`） | 遵循 `GLYPHMETRICS` |
| `2` | `0x44f880` | `GetGlyphOutlineA` (`GGO_BITMAP = 1`) | `bold ? 700 : 0` | 支持 `"@"` 竖排与 `MAT2` 90° | **纯黑硬阴影**：先在 `(+3, +3)` 写纯黑 `0x00000000` 位图，再在 `(0, 0)` 覆写前景位图 | 包围盒宽高各加阴影余量，遵循 `GLYPHMETRICS` |
| `3` | `0x44fca0` | `GetGlyphOutlineA` (`GGO_GRAY8_BITMAP = 6`) | **`bold ? 700 : 0`** | **固定单位矩阵 `MAT2 = I`**（仅横排） | **主对话默认模式**：调 `0x435700(color)` 填前景 BGR；写倒置透明度 **`A = ~((g * 255) >> 6) & 0xFF`**（`0xFF - a`）；设 `blend_mode = 0, sub = 0`（Porter-Duff `Over` 混合，**无阴影**） | **强制等宽覆写（`0x44fe4b..0x44fe98`）**：`gmCellIncY = font_h`；`gmCellIncX = is_dbcs(ch) ? font_h : (font_h >> 1)` |
| `4` | `0x44ff30` | `TextOutA` 离屏 DC | `bold ? 700 : 0` | 仅横排 | 兼容位图 `TextOutA` 无阴影绘制（`^a` 动画字用此路径 `0x441eb0`） | GDI `GetTextExtentPoint32A` |
| `5` | `0x450190` | `TextOutA` 离屏 DC | `bold ? 700 : 0` | 仅横排 | `(+3, +3)` 纯黑 `TextOutA` 阴影 + `(0, 0)` 前景 `TextOutA` | GDI `GetTextExtentPoint32A` |

> **关键细节（Rust 移植必须一致）**：
> - `IsDBCSLeadByte` 实为内联 CP932 判定函数：`0x452a2a(b)` 匹配 `0x81..=0x9F || 0xE0..=0xFC`；`0x452a3b(b)` 匹配 `0x40..=0x7E || 0x80..=0xFC`。
> - **`mode 3` 强制全角/半角等宽**（`0x44fe4b..0x44fe98`）：无论 GDI 返回的 `gmCellIncX` 为何，双字节字符前进永远等于 `font_height`，单字节 ASCII/半角片假名永远等于 `font_height / 2`。这保证原版台词每行严格按 `35` 个全角格（或 `70` 半角格，随字号缩放）对齐折行！
> - **描边与阴影**：主对话（`mode 3`）**既无 1px 描边也无投影**（投影仅用于 `mode 2` / `mode 5`，靠 `tbox00/01/11..14` 的半透明暗底保证可读性）。

2. **换行排版与行距（`0x441fe0`）**：
   - 行高 `line_advance = line_max_height + 5` px（横排每行额外加 **5 px** 垂直间距；竖排每列 `col_max_width + 5` px 水平间距）。

   - 引擎核心多媒体定时器 `timeSetEvent`（`0x447a90`）周期为 **`50 ms`（20 Hz）**，通过向主窗口投递 `0x419` 消息驱动 `0x447c00` 更新文本。
   - `confscrn` 将文字速度配置 `0x47137a` 写入：**慢 (`msp_slw`) = `4`**、**中 (`msp_nom`) = `1`**、**快/瞬切 (`msp_now`) = `0`**（默认新建为 `1`）。
   - 逐字推进（`0x440ea0` + `0x436110`）：对每个字元检查其 `per_glyph_delay`（由当前 `speed` 或 `^d` 写入）：
     - 若 `delay == 0`：立即显示该字元并**在同一 tick 内循环继续**显示所有后续 `delay == 0` 的字元（从而 `speed=0` 或 `^d0` 实现单帧瞬显）；
     - 若 `delay > 0`：显示当前字元后向文本等待器传入 `delay - 1`（`0x4361e0`），随后每 50 ms tick 递减等待直至达到 `delay` ticks（即 `speed=1` 为 **50 ms/字**，`speed=4` 为 **200 ms/字**）再显示下一个字元。
   - Auto 模式等待时长：全局 `u16` `DAT_00471394`（默认为 **`1500` ms**，单位 ms，在 `confscrn` 中以滑块调节，配合 `0x447b30` / `0x447b90` 计时，遇语音播放则等待语音结束且不抢断）。

### 4.2 `IDirectSoundBuffer::SetVolume` 音量换算与淡入淡出精确数学模型

1. **输入音量（`0..=255`）→ DirectSound 百分之一分贝 `mb ∈ [-10000, 0]`**：
   - **SE / Voice（`0x448d00`）**：
     $$\text{mb} = \left\lfloor \frac{(\text{vol} - 255) \times 5300}{255} \right\rfloor \quad (\text{范围 } -5300..0 \text{，传入 } \text{0x45a200} \text{ 钳位至 } [-5000, 0])$$
   - **BGM（`0x448fd0`）**：
     $$\text{mb} = \left\lfloor \frac{(\text{vol} - 255) \times 3000}{255} \right\rfloor \quad (\text{范围 } -3000..0 \text{，传入 } \text{0x45a200} \text{ 钳位至 } [-5000, 0])$$
   - **静音开关关闭（`0x459fe0`）**：直接调用 `IDirectSoundBuffer::SetVolume(-10000)`（`-100 dB` 完全静音）。
   - **Rust / CoreAudio / AVAudioEngine 线性幅度换算**：将 DirectSound 分贝值转线性增益 $g = 10^{\text{mb} / 2000}$（注意 `mb == -10000` 强制 `g = 0.0`；即使 `vol == 0` 在 BGM `-3000 mb` = `-30 dB` 仍有微弱余音，只有静音开关关闭时才为 `0.0`，须严格还原 `mb` 曲线！）。

2. **异步淡入淡出步进定时器（`0x459a80` / `0x45efd0` / `0x45a7f0`）**：
   - 每路声音对象启动独立 `timeSetEvent` 定时器，**步进周期固定为 `100 ms`**（`*(u32*)(this + 0x6c) = 0x64`）。
   - 默认总步数 **`total_steps = 150` (`0x96`, `15.0 s`)**，可由 `0x458d50(steps)`（若 `steps != 0`）覆盖（BGM 直接传入淡入参数，SE/Voice 循环或渐变传入 `param_4 * 50`）。
   - 每 `100 ms` 执行 `step += 1`（`1..=total_steps`）：
     - **淡入**：$\text{mb}_{\text{cur}} = \left\lfloor \frac{(\text{target\_mb} + 5000) \times \text{step}}{\text{total\_steps}} \right\rfloor - 5000$
     - **淡出**：$\text{mb}_{\text{cur}} = \left\lfloor \frac{(\text{target\_mb} + 5000) \times (\text{total\_steps} - \text{step})}{\text{total\_steps}} \right\rfloor - 5000$
     - 当 `step == total_steps` 时：若为淡出终止标志 `*(this + 0x34) != 0` 则停止释放缓冲并停用定时器。
